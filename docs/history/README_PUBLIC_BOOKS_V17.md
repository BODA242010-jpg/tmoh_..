# طموح V17 — رفع المناهج لجميع الطلاب (مكتبة عامة)

## مهم: ما الفرق بين الإضافة الشخصية والنشر العام؟
- زر «أضف الكتاب PDF من جهازك» الموجود داخل موقع الطالب يظل خاصًا بهذا الطالب فقط، في المتصفح الحالي.
- الكتب التي تضعها إدارة الموقع في `tmoh-public-books.json` تظهر لجميع الطلاب عن طريق GitHub Pages.
- **الفهرس في هذه الحزمة فارغ عمدًا**: لم ترفق كتب PDF أو روابط مباشرة موثقة بعد. لا تعلن أن الكتب كلها منشورة.

## طريقة نشر كتاب رسمي عن طريق الرابط (المفضلة إذا لم يُسمح بإعادة استضافة PDF)
1. افتح بوابة الوزارة https://studentbooks.moe.gov.eg/Books
2. اختر الصف والمادة والفصل، وافتح الكتاب. تأكد أن الملف يخص السنة الدراسية المطلوبة.
3. انسخ **رابط PDF المباشر** من النطاق الرسمي. رابط صفحة البحث وحده لا يكفي للقارئ؛ يمكن ربطها في وصف المصدر، لكن لا تضفها إلى حقل url حتى لا تظهر كرابط PDF غير صالح.
4. افتح ملف `tmoh-public-books.json` في المشروع. أضف عنصرًا في `books`:

```json
{
  "id": "pub-prep1-arabic-t1-2026",
  "grade": 0,
  "subject": "اللغة العربية",
  "term": "1",
  "title": "كتاب اللغة العربية - الترم الأول",
  "edition": "2026-2027",
  "source": "مكتبة وزارة التربية والتعليم",
  "url": "ضع_هنا_الرابط_الرسمي_الحقيقي.pdf"
}
```
هذه صيغة تعليمية فقط. **لا تنشر السطر url بالمثال**؛ يجب استبداله برابط حقيقي موثوق.
5. احفظ الملف وارفعه إلى جذر مستودع GitHub الذي يشغّل Tmoh. عند اكتمال GitHub Pages يظهر الكتاب لكل الطلاب.

## طريقة نشر PDF تمتلك تصريحًا لإعادة نشره
1. ضع ملف PDF باسم لاتيني بسيط، مثل `arabic-t1-2026.pdf` داخل `books/prep1/` (أولى إعدادي).
2. أضف عنصرًا مطابقًا للفهرس، وبحقل `url`: `books/prep1/arabic-t1-2026.pdf`.
3. ارفع **الملف نفسه** مع `tmoh-public-books.json` إلى المستودع، وليس الفهرس وحده.
4. تأكد أن الرابط المباشر للملف يعمل على GitHub Pages. لا ترفع كتبًا محمية إلى استضافة عامة دون تصريح.

## أرقام الصفوف
| grade | الصف | المجلد |
|---|---|---|
| 0 | أولى إعدادي | books/prep1/ |
| 1 | تانية إعدادي | books/prep2/ |
| 2 | تالتة إعدادي | books/prep3/ |
| 3 | أولى ثانوي | books/sec1/ |
| 4 | تانية ثانوي | books/sec2/ |
| 5 | تالتة ثانوي | books/sec3/ |

قيم `term`: `1` للأول و`2` للثاني و`annual` لكتاب السنة كاملة.
اسم `subject` يجب أن يطابق اسم المادة الموجود في طموح، ويمكن الاستعانة بجدول المواد في `tmoh-schoolbooks.js`. كل كتاب يحتاج `id` فريدًا يبدأ بـ `pub-`.

## إضافة كتاب أو تعديل موقعه لاحقًا
حرّر `tmoh-public-books.json` فقط (بالإضافة لرفع ملف PDF إذا استُخدمت استضافة محلية). الفهرس يتحدّث عند زيارات الطلاب الجديدة، وقد يحتاجون تحديث الصفحة. تغيير رابط PDF قد يتطلب منهم إعادة فتح الكتاب.

## حماية البيانات والموارد
- لن يُمسح `tmoh2` أو الشات بوت؛ فهرس الكتب العام منفصل.
- يحفظ كل طالب رقم آخر صفحة داخل ملفه المحلي ويمكن تصدير تقدم الصفحات في نسخة Tmoh الاحتياطية.
- ملفات PDF المنشورة على GitHub عامة للجميع، فلا ترفع ملفات شخصية أو كتبًا بدون إذن توزيع.
- قد تمنع الوزارة تضمين ملفاتها داخل iframe؛ زر «فتح الكتاب في نافذة جديدة» هو البديل.
- الموقع ثابت (GitHub Pages): لا توجد لوحة مسؤول آمنة ترفع إلى GitHub مباشرة من المتصفح. استخدام GitHub رفع يدوي يتطلب صلاحيات صاحب المستودع.
- إذا كان عدد الكتب كبيرًا، الأفضل استخدام روابط الوزارة أو تخزين ملفات مصرح بها في خدمة عامة مناسبة، بدل رفع مئات الملفات الثقيلة على GitHub.

## خطوات الرفع من الكمبيوتر
1. افتح https://github.com/BODA242010-jpg/tmoh9
2. خذ نسخة احتياطية من الملفات والبيانات الحالية.
3. اضغط Add file → Upload files، وارفع **ملفات التحديث كلها من جذر الحزمة**، وليس ملف ZIP نفسه.
4. بعد رفع PDF وفهرسه، افتح `https://boda242010-jpg.github.io/tmoh9/#/books`، واختر الصف والمادة والترم.
5. جرّب مع متصفح/هاتف مختلف للتأكد أنه كتاب عام وليس شخصيًا.

## حالة التسليم
- واجهة عرض الكتاب العام وفهرسه جاهزان للاستخدام.
- لم تُضف كتب فعلية حتى تزودنا بالملفات/الروابط الموثقة.
- لم يُنشر شيء إلى GitHub عبر هذه الحزمة؛ صلاحية الكتابة من الاتصال الحالي غير متاحة.
