# Tmoh V17 — Shared Schoolbook Catalog

- إضافة فهرس عام مشترك `tmoh-public-books.json` يدعم ستة صفوف ومادة وترم ومصدر وسنة طبعة.
- عرض الكتب العامة في صفحة المناهج مع احتفاظ كل طالب بملفاته الشخصية منفصلة.
- قارئ PDF للكتب العامة مع زر فتح المصدر إذا مُنع التضمين.
- حفظ آخر صفحة لكل طالب في `tmoh2` وإدراج تقدم الصفحات في التصدير/الاستيراد.
- فصل تخزين PDFs الكبيرة عن كاش PWA، وتحديث اسم كاش التثبيت.
- عدم تعديل خدمة ChatBook أو زر إضافة الكتب الشخصية.
- لا توجد كتب فعلية ضمن فهرس هذه النسخة؛ يبدأ فارغًا حتى إضافة محتوى موثق.
