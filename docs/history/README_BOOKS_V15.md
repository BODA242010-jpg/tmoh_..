# Tmoh V15 — مكتبة المناهج والكتب حسب الصف

**الحالة: تجهيز تفاعلي للمكتبة، وليس رفع جميع كتب الوزارة.**

## النطاق
- ستة صفوف مصرية: أولى/تانية/تالتة إعدادي، وأولى/تانية/تالتة ثانوي.
- لكل صف أقسام مواد مستقلة، وفصل أول وثانٍ وكتاب سنوي؛ مادة البكالوريا لها منفذ مستقل لبوابة الوزارة.
- لكل مادة إضافة كتاب PDF **من جهاز الطالب** أو ربط **رابط PDF مباشر من نطاق الوزارة**، ثم قراءته داخل Tmoh إذا سمح المتصفح/المصدر بذلك.
- تخزين PDF شخصيًا في IndexedDB (حد نظري 160 ميجابايت للملف؛ الحد الفعلي حسب مساحة الجهاز).
- حفظ آخر صفحة يدويًا، وتنزيل الكتاب، وفتح نسخة مستقلة، والانتقال للعداد، وتجهيز سؤال للشات بوت.
- بقاء الدروس التأسيسية القديمة في قسم قابل للفتح، دون حذف أو دمج غير آمن.
- لم نُضِف كتب PDF افتراضية مزيفة. قوائم المواد **تصنيفات للتصفح وليست شهادة بأن كل كتاب متوفر أو مطابق للسنة**.

## لماذا لا يحتوي الملف على الكتب الستة الصفوف كاملة؟
المصدر الرسمي هو https://studentbooks.moe.gov.eg/Books، والبكالوريا https://ellibrary.moe.gov.eg/EgyptianBaccalaureate/. بعض الملفات كبيرة جدًا (قد يتجاوز كتاب 100 ميجابايت)، ولا تتوفر كافة روابط PDF المباشرة بطريقة تمكن التحقق والنسخ، كما يلزم التأكد من حقوق إعادة الاستضافة على GitHub. لذلك **لم ننسخ الكتب الأصلية أو ندّعي رفعها**.

لإكمال طلب رفع كافة المناهج داخل الموقع نحتاج ملف ZIP يحتوي PDFs الرسمية المحددة للسنة والفصل والصف/الشعبة، مع توضيح حق الاستضافة؛ أو روابط PDF رسمية مباشرة لكل كتاب. يمكن تخزين نسخ تملك حق نشرها في مجلد books/ في المستودع وإعداد فهرس موثق بأسماء الملفات، أو عرض النسخ الأصلية عن بعد دون نسخ إذا سمح المصدر بذلك. هذا الجزء لم يتم بعد.

## النشر
1. خذ نسخة احتياطية من بيانات الطالب من إعدادات Tmoh، واحتفظ بالكتب الأصلية على جهازك أيضًا.
2. ارفع **محتويات** هذه الحزمة مباشرة إلى **جذر** المستودع BODA242010-jpg/tmohhhh (ليس المجلد ككل).
3. استبدل الملفات السابقة بنفس الاسم، ولا تمسح تخزين الموقع أو بيانات المتصفح.
4. بعد اكتمال GitHub Pages، افتح الموقع ثم #/books أو #/curriculum، وجرب تحميل كتاب PDF حقيقي من جهازك.
5. افتح الكتاب ثم احفظ الصفحة، أغلق الموقع وافتحه للتحقق من استمرار البيانات.
6. اختبر على متصفح موبايل؛ بعض متصفحات iOS لا تعرض PDF داخل iframe: استخدم زر «فتح منفصلًا» أو «تنزيل».

## خصوصية وقيود
- حفظ ملف الطالب لا يزال **محليًا افتراضيًا** بالمفتاح `tmoh2`.
- بيانات فهرس الكتب (عنوان، صف، مادة، صفحة...) داخل ملف الطالب؛ **ملف PDF نفسه لا يُرفع تلقائيًا إلى Cloudflare أو Supabase أو GitHub**، ولا ينتقل إلى جهاز آخر عند استيراد ملف JSON.
- لا يستطيع الشات بوت قراءة محتوى PDF الخاص تلقائيًا؛ زر «اسأل عن فقرة» يملأ نموذجًا، وعلى الطالب نسخ الفقرة أولًا لتجنب الإجابة غير المستندة إلى مصدر.
- الربط الحكومي قد يُمنع تضمينه داخل iframe بسياسة المصدر؛ افتح المصدر في نافذة جديدة في هذه الحالة.
- الكتب الرسمية تدعم مراحل التعليم العام المصري؛ قد تتغير المواد حسب الشعبة/المدارس/النظام (الثانوية/البكالوريا) ويجب مراجعة الوزارة قبل اعتمادها.
- لم يُعدّل كود Cloudflare Worker، ولم يُغيّر `CONFIG.AI_URL`.

## تقرير الفحص
- `node --check` لملفات التطبيق والمكتبة: نجح.
- 21 تحقق منطقي بالبيئة المعزولة: اختيار الصفوف 0–5، المواد، حفظ عنوان كتاب ورابط PDF، حفظ آخر صفحة، رفض روابط غير رسمية، وعدم حذف الدروس القديمة: نجح.
- ملفات JS/CSS المشار إليها في index.html موجودة. ملفات chatbot/saved data الأصلية لم تتغير، عدا إضافة فهرس مكتبة الكتب لاستيراد بيانات الطالب.
- **لم يُختبر عبر متصفح إنتاج حقيقي**؛ متصفح الاختبار منع الملاحة لكل عناوين الشبكة/الملفات في البيئة الحالية (`ERR_BLOCKED_BY_ADMINISTRATOR`). رفع الكتب الحقيقية وقراءة PDF في المتصفح يحتاجان اختبارًا بعد النشر.
- **لم يُنشر على GitHub:** أداة GitHub رفضت إنشاء فرع بصلاحية 403.
