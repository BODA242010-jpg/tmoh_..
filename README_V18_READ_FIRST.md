# Tmoh V18 — فهرس الكتب المرتبط بمصادر الوزارة

## اللي اتعمل
- **29 رابط PDF مباشر منشور على نطاق `elearnningcontent.blob.core.windows.net`** للعام `2026_2027` كما ورد في فهارس تعليمية عامة (عدد تانية ثانوي 28، تالتة ثانوي 1).
- تقسيم الكتب حسب الصف والمادة والفصل الدراسي، مع رابطين لمكتبة الوزارة وفهرس مساعد للصفوف الستة.
- لم يتم تنزيل الكتب وإعادة نشرها أو فحص استجابة كل رابط. الروابط الموجودة لا تعني أن جميع الكتب تم التحقق منها وأنها صالحة لحظة الاستخدام.
- فهرس المرحلة الإعدادية وأولى ثانوي يوصل للمصدر المعتمد أو فهرس خارجي، لكنه **ليس ملف PDF مرفوعًا**.
- إعدادات الشات بوت الأصلية وبيانات الطلاب (`tmoh2`) لا تتغير.

## المصادر
1. بوابة الوزارة: https://studentbooks.moe.gov.eg/Books
2. البكالوريا: https://ellibrary.moe.gov.eg/EgyptianBaccalaureate/
3. منشور يضم روابط تانية ثانوي على نطاق استضافة الوزارة: https://t.me/s/Shima_Hekal?before=10478
4. رابط فيزياء تالتة ثانوي ضمن منشورات تعليمية عامة: https://www.myschool77.com/2026/10/physics-book-grade-12-pdf-2027.html
5. فهرس مساعد مستقل بجميع الصفوف، يذكر أنه راجع روابط 2026–2027، لكننا لم نفحص كل ملف منه: https://miskeg.app/books/

## طريقة النشر (مهمة)
1. احفظ نسخة احتياطية من المستودع وملفات الطلاب أولًا.
2. ارفع محتويات ZIP إلى جذر مستودع Tmoh الذي يشغل موقعك (**ليس ZIP نفسه**).
3. افتح `#/books`، واختار الصف الثاني الثانوي ← الفيزياء ← الترم الأول؛ ستجد 3 كتب بلغات مختلفة. جرّب فتح الملف في نافذة جديدة.
4. اختر أولى إعدادي؛ إن لم تتوفر نسخة PDF مباشرة، استخدم زر المكتبة الرسمية أو الفهرس الخارجي.
5. لو الرابط تعطل، أزل مدخله أو حدّث الرابط الصحيح من `tmoh-public-books.json`.
6. لا ترفع ملفات PDF إلى GitHub دون التأكد من ترخيص إعادة النشر. إذا كان الملف على سيرفر الوزارة، يكفي الربط إليه.
